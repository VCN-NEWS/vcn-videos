# vcn-videos

Moteur de production des reels VCN — Vice City News (GTA 6).

- `engine/` : génération de la carte stylisée, des cartes animées, des sous-titres mot à mot et du mixage.
- `videos/` : vidéos finales prêtes à publier (hébergement temporaire pour la publication).
- `covers/` : couvertures 9:16.
